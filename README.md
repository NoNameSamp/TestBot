# Tatiana Birthday Button Bot

Бот на Python (python-telegram-bot 21.x), управляющий нижней (reply) клавиатурой
с кнопкой «Поздравить Татьяну с Днем Рождения» в чате. Доступ — только у пользователя
с Telegram ID `6788511742`.

Клавиатура снизу в Telegram привязана к чату, а не к конкретному боту: последнее
отправленное в чат сообщение с разметкой клавиатуры и определяет, что видят
пользователи. Поэтому:

- Как только этот бот добавляется в группу, он **автоматически** шлёт
  `ReplyKeyboardRemove`, что должно принудительно скрыть старую кнопку — даже
  если бот, который её изначально показал, уже удалён из чата.
- `/remove_button` — то же самое вручную (только для ID `6788511742`).
- `/restore_button` — заново показывает клавиатуру с кнопкой «Поздравить Татьяну
  с Днем Рождения» (только для ID `6788511742`). При нажатии в чат придёт
  поздравление от имени нажавшего.

Для всех остальных пользователей `/remove_button` и `/restore_button` не делают
ничего (бот молчит).

⚠️ Оговорка: поведение клиента Telegram в этой части официально не полностью
задокументировано — в подавляющем большинстве случаев это работает именно так,
но если после добавления бота кнопка не пропадёт, попробуйте `/remove_button`
вручную, либо участникам может понадобиться просто открыть чат заново.

## Деплой на GitHub + Render

1. Загрузите эти файлы (`bot.py`, `requirements.txt`, `render.yaml`) в свой
   репозиторий на GitHub.
2. На [render.com](https://render.com) создайте **New → Web Service**, подключите
   этот репозиторий.
3. Render подхватит `render.yaml` автоматически (Blueprint), либо настройте вручную:
   - Build command: `pip install -r requirements.txt`
   - Start command: `python bot.py`
4. В разделе **Environment** добавьте переменную:
   - `BOT_TOKEN` — токен вашего бота от [@BotFather](https://t.me/BotFather)
   - (`ADMIN_ID` уже проставлен как `6788511742` в render.yaml, менять не нужно)
5. Деплой. Render сам создаёт переменную `RENDER_EXTERNAL_URL` — бот использует её
   для webhook, ничего дополнительно указывать не нужно.
6. Добавьте бота в нужный чат, дайте ему права отправки сообщений.
7. Напишите `/restore_button` от аккаунта с ID `6788511742` — появится кнопка.

## Ограничение бесплатного плана Render

На бесплатном тарифе Render "засыпает" сервис после ~15 минут без HTTP-запросов.
Поскольку бот работает через webhook (Telegram сам "будит" его новым сообщением),
для обычного использования это не критично — задержка на первое сообщение после
простоя может составить несколько секунд.

## Как узнать свой Telegram ID (если понадобится сменить ADMIN_ID)

Напишите боту [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш числовой ID.
