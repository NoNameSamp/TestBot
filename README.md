# Бот-доска объявлений с мини-приложением

## Файлы
- `index.html` — мини-приложение (форма: текст + фото-превью)
- `bot.py` — сам бот
- `requirements.txt` — зависимости

## Шаг 1. Создать бота
1. В Telegram напишите **@BotFather**
2. `/newbot` → задайте имя и username
3. Сохраните токен — это `BOT_TOKEN`

## Шаг 2. Захостить index.html
Нужен HTTPS-адрес (обязательное требование Telegram). Проще всего:
- **GitHub Pages** — залить `index.html` в репозиторий, включить Pages в настройках
- или **Netlify / Vercel** — перетащить файл, получить ссылку за минуту

Полученный адрес (например `https://username.github.io/ad-bot/`) — это `WEBAPP_URL`.

## Шаг 3. (Опционально) Канал для публикации
Если хотите, чтобы объявления публиковались в отдельный канал:
1. Создайте канал, добавьте бота администратором
2. Узнайте id канала (например, через @userinfobot или переслав сообщение из канала в @getidsbot) — обычно вида `-100xxxxxxxxxx`
3. Это `CHANNEL_ID`

Без этого шага бот в демо-режиме будет просто присылать готовое объявление вам в личку — этого достаточно, чтобы проверить, что всё работает.

## Шаг 4. Запуск бота
```bash
pip install -r requirements.txt

export BOT_TOKEN="ваш_токен_от_botfather"
export WEBAPP_URL="https://ваш-хостинг/index.html"
export CHANNEL_ID="-100xxxxxxxxxx"   # необязательно

python bot.py
```

Бот будет работать, пока запущен процесс. Для постоянной работы разместите его на любом сервисе, который держит процесс живым: Railway, Render, обычный VPS с `systemd`/`screen`, и т.п. Локальный запуск подходит только для тестов.

## Как это выглядит для пользователя
1. `/start` → кнопка «📌 Опубликовать объявление»
2. Открывается мини-приложение → пишет текст, при желании прикрепляет фото → «Опубликовать»
3. Если было фото — бот просит прислать его следующим сообщением (или `/skip`)
4. Объявление публикуется

## Возможные доработки
- Хранение истории объявлений (потребуется база данных, например SQLite)
- Модерация перед публикацией
- Категории/теги объявлений
- Кнопка «Мои объявления» / удаление своего объявления
